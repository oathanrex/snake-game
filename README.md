# 🐍 Snake — Premium Edition

A polished arcade Snake game with neon aesthetics, multiple cabinet themes, combo scoring, particle effects, and fully responsive mobile controls — built with nothing but vanilla HTML, CSS, and JavaScript.

## ✨ Features

- **3 Game Modes** — Classic, No Walls (wrap-around), and Obstacles (hardcore)
- **4 Difficulty Levels** — Easy, Normal, Hard, Insane
- **3 Cabinet Themes** — Neon Arcade, Midnight, and a retro Nokia-style monochrome LCD, each with its own colors, glow, and obstacle styling
- **Combo & Bonus System** — chain food pickups for combo multipliers, hunt down Star / Ruby / Crown bonus pickups before they expire
- **Progressive Difficulty** — speed ramps up automatically as you level up
- **Local Top-5 Leaderboard** — save your initials when you land a high score
- **Premium Visuals** — neon glow effects, particle bursts, screen shake, smooth animations
- **Accessible** — keyboard-friendly, screen-reader announcements, respects reduced-motion preferences
- **Mobile-First Controls** — on-screen D-pad plus swipe gestures, tuned for touch
- **Zero Dependencies** — no build step, no frameworks, just open `index.html`

## 🕹️ Controls

| Platform | Controls |
|----------|----------|
| Desktop | Arrow Keys or WASD |
| Mobile | Swipe or on-screen D-pad |
| Pause | `Esc` or the on-screen pause button |
| Confirm / Start | `Enter` |

## 🖥️ Cabinet Styles

| Theme | Vibe |
|-------|------|
| **Neon** | Cyan & pink arcade cabinet glow |
| **Midnight** | Cool blue/teal stealth mode |
| **Nokia** | Monochrome retro LCD, inspired by classic handheld Snake |

## 🛠️ Tech Stack

- Pure HTML5, CSS3, and JavaScript (ES6+)
- Canvas API for all game rendering
- Web Audio API for sound effects
- `localStorage` for high scores and leaderboard persistence
- No external dependencies, no build tools required

## 🚀 Run Locally

```bash
git clone https://github.com/oathanrex/snake-game.git
cd snake-game
# just open index.html in your browser — no build step needed
```
