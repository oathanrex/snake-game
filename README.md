# 🐍 Snake - Premium Edition

A polished arcade Snake game with neon aesthetics, multiple game modes, particle effects, and responsive mobile controls.

![Snake Preview](https://img.shields.io/badge/Play-Live%20Demo-00f5ff?style=for-the-badge)

## 🎮 [Play Now](https://oathanrex.github.io/snake-game/)

## ✨ Features

- **3 Game Modes**: Classic, No Walls, Obstacles
- **4 Difficulty Levels**: Easy, Normal, Hard, Insane
- **Premium Visuals**: Neon glow effects, particle explosions, smooth animations
- **Mobile Support**: Touch controls + swipe gestures
- **Progressive Difficulty**: Speed increases as you level up
- **Local High Scores**: Track your best scores

## 🕹️ Controls

| Platform | Controls |
|----------|----------|
| Desktop | Arrow Keys or WASD |
| Mobile | Swipe or Touch Buttons |
| Pause | ESC or P |

## 🛠️ Tech Stack

- Pure HTML5, CSS3, JavaScript
- Canvas API for rendering
- Web Audio API for sound effects
- No external dependencies
